# Project Workflow — Lista de Algoritmos

## Perfil
Exercícios acadêmicos — **processo mínimo**.

## Fluxo
Enunciado → entender entradas/saídas → algoritmo → implementação → testes → revisão → commit.

## Regras
- Resolver primeiro da forma mais simples e correta.
- Usar conceitos compatíveis com o conteúdo estudado, salvo quando a tarefa pedir algo diferente.
- Manter nomes claros e lógica legível.
- Evitar bibliotecas e abstrações desnecessárias.
- Testar caso normal, caso limite e um caso alternativo relevante.
- Identificar a causa do erro antes de reescrever a solução.
- Tratar cada exercício como uma tarefa pequena e verificável.

## Checklist
1. Entendi o enunciado.
2. Defini entrada e saída esperadas.
3. Implementei.
4. Executei casos de teste.
5. Revisei legibilidade.
6. Corrigi antes de avançar.
